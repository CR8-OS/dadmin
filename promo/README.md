# Promo

Launch and storefront material for Dadmin. Ko-fi listing copy, social cards,
screenshots — anything made to post rather than to ship.

**Most of this folder is deliberately not committed.** The `.gitignore` excludes
everything here except this README and `kofi-listing.md`.

The reason is licensing. The repo is MIT, which grants anyone the right to use,
modify, sublicense and sell what is in it. That is a fine promise to make about
original work. It is not a promise anybody can make about a stock illustration,
a reference image, a screenshot of someone else's product, or a font you hold a
license to rather than own. Posting that material is ordinary. Republishing it
under a license you do not hold is a different thing, and the folder boundary is
what keeps the two apart.

`scripts/build-plugin.mjs` excludes this folder from the shipped bundle for the
same reason.

## The header artwork

`dadmin-header-cream.png` sits in the repo root and is currently covered by the
MIT license along with everything else. That is correct **only if the
illustration is original work**.

If it came from a stock library — Canva's element library included — it is
licensed to the account that made it, not owned by it, and most stock licenses
specifically prohibit sublicensing, use as a brand mark, and inclusion in
products that are sold. MIT does all three. In that case the fix is the same
shape as the one above: move the artwork out of the MIT grant with an explicit
carve-out in LICENSE and a note in the README, or replace it with something
original or public domain.

This is unresolved. It is written down here rather than left as something
someone remembers, because the version that bites is the one nobody wrote down.
